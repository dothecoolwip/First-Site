## 1. What the game is

- A 3D game (three.js r149) that runs in the browser on phone, tablet and PC, installable as a PWA. One `index.html` (about 16.5 MB, everything inlined: models as base64, sounds, scripts).
- Setting: a **real-life medieval festival** with people in costume. **No monsters, dragons or magic gameplay.** Weapon "skins" are cosmetic only. Halloween ghosts/graveyard decoration are fine.
- Core loop: you walk a big open "realm" (festival fairground + five districts), talk to vendors, gather materials, and fight bots or friends in 1v1 to 12v12 buhurt matches with real buhurt rules (down = out, cards, rounds).
- Live at **https://buhurt-steel-and-tape.vercel.app** (Vercel project `buhurt-steel-and-tape`, team id `team_48w65sgEoANAtsp7G3WioNnz`), deployed from the GitHub repo **dothecoolwip/First-Site** branch `main` (the repo holds the built `index.html`, `sw.js`, `manifest.webmanifest`, icons, `admin.html`, `PLAN-realm.md`, this file).
